# existence-bible
[ref: #existence-bible-readme]

Mandatory existence-review standard for all code work, always loaded (`always: true`).

## What it does
[ref: #existence-bible-readme-purpose]

Every line of a changeset must earn its existence: rule families A–K govern keep/revert/delete decisions, abstraction justification, types and layers, errors, naming, flow, local development, migration, logging, and review-answer discipline. On conflict with language style guides, this standard wins.

## Consumers
[ref: #existence-bible-readme-consumers]

- `discuss-first` — cites rule ids A1–K4 for every keep/revert/delete decision and abstraction justification while the co-implementation mode is active.
- `code-review` — the Existence Inquisition specialist subagent executes the standard adversarially against every review target.
- Any agent — the standard is always loaded; apply it to every keep/revert/delete call.
